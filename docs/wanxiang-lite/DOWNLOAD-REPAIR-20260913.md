# 输入方案与语法模型：下载与安装修复

## 已确认的问题

旧 BITS 任务在 `D:\RIME\.weasel-packages` 下下载。卸载／目录变化后，
目标父目录不存在，任务返回 `LocalFile / 系统找不到指定的路径`。
界面却把所有临时错误描述为网络错误，重新下载也优先恢复旧任务，
没有检查目录和实际临时文件。

## 本次实现

- 新任务缓存位于当前用户 LocalAppData 下的
  `Rime\Weasel\Downloads\<模型 SHA256>`，与 Rime 用户文件夹分开。
- 旧任务按名称、来源 URL、文件数量和文件名核对；打开窗口不会擅自恢复暂停任务。
- 检查 BITS 的实际临时文件，不能把尚未生成的目标 `.part` 当作缓存丢失。
- 缓存仍在时，重试先恢复目标父目录再续传；缓存已丢失时明确显示“重新下载”，
  点击后取消失效任务，在新的缓存目录建立任务。
- 网络错误、磁盘空间和本地路径／权限错误分开说明；状态文字仅在变化时刷新。
- 显示 400.9 MiB（420343852 字节）；活动下载显示已下载／总大小及百分比。
- 下载完成后校验大小、SHA256；先复制到用户文件夹所在卷并复核，
  再替换模型和部署，保留原有回滚流程。失败后保留已验证缓存供再次安装。
- 模型部署和事务提交成功后，清理本次下载文件；失败或暂停时保留缓存。
  清理失败不撤销已经成功的部署，记录待清理标记，下次打开管理器时重试。
- 设置窗口压缩无用空白，详情可滚动，操作按钮右对齐，显示实际用户文件夹。
  顶部不显示方案版本，检查更新在后台执行；保存按钮仅在选择有修改时可用。
- 交互式安装始终确认用户文件夹；旧 Profile/Hant 值不再导致静默跳过。
  校验绝对路径和可写性；不存在的文件夹经确认后创建。
  取消安装选项后不会继续部署。原静默安装参数继续使用原路径。

## 验证记录

- 独立目录完整下载 CNB 官方模型，实际 SHA256：
  `9f80530f470033cfb6d4b44bb861b540f64100426f92dd0f87140883632a3d93`，匹配固定值。
- 独立任务暂停于 1320940 字节，在新的 PowerShell 进程中恢复至 2377708 字节，
  原进度保留；随后取消该测试任务。没有修改正式模型、旧任务或输入法配置。
- 代码格式、PowerShell 语法和差异空白检查通过。
- CI 新增实际模型管理器事务测试：新安装、替换回滚、校验失败、
  保留用户模型、已校验缓存复用、进程退出后的恢复。
  测试仅替换模型常量为 4 KiB 固定样本，并隔离 IPC 与用户目录。

完整下载／续传验证证明来源及 BITS 可用，不等同于新程序已经通过端到端验证。
编译、事务测试的最终结果须以对应提交的 CI 结果为准；安装后的实际窗口、
旧任务修复、跨磁盘用户目录、安装取消仍需成品验证。
