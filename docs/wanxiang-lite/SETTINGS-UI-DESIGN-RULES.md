# 小狼毫设置界面设计规则

本文件是小狼毫设置界面的强制设计规范。现有页面调整和后续新增页面均须遵守；
不得在单个页面中临时定义另一套尺寸、圆角、按钮或对齐方式。

## 1. 固定框架

- 所有设置页面共用同一个顶层窗口，切换页面不得改变窗口尺寸和位置。
- 顶层窗口、标题栏、系统边框和阴影在整个设置会话中只创建一次；各设置页必须
  作为无边框子页面切换，不得通过替换顶层窗口实现导航。
- 内容框架以 `SettingsNavigation.h` 为唯一尺寸来源：内容区 `540 × 286 DLU`，
  导航栏宽度 `116 DLU`，页面内容边距 `14 DLU`，页面主体宽度
  `512 DLU`。
- 窗口标题统一为“小狼毫设置”。右侧内容区不重复显示当前页面大标题，当前页
  由左侧导航栏选中状态表达。
- 左侧导航栏使用与右侧内容区可辨别但克制的浅色底色，并始终保持固定宽度。
- 四个主导航项统一使用 `16 DLU` 高度和 `2 DLU` 纵向间距；导航项不得因页面
  不同而改变尺寸。圆角项绘制前必须先完整铺设导航栏底色，避免圆角外露出异色
  直角像素。
- 导航栏固定划分为顶部导航、中部应用操作、底部用户文件夹三个区域。“应用”
  按钮上方及应用操作与用户文件夹之间使用同宽、低对比度单像素分隔线；导航项
  下方不单独放置分隔线。分隔线左右边缘与导航项和按钮对齐。
- 存在未应用更改的页面必须在导航名称最右侧显示统一的蓝色圆点；圆点右对齐、
  垂直居中，并为页面名称预留固定空间。应用更改后圆点必须立即消失。
- 用户文件夹固定在导航栏最下方，并显示为与主导航项同宽、同高的单行辅助入口。
  单行依次显示文件夹图标、标题、次级路径文字和打开箭头，整行可点击，路径过长
  时使用省略显示。默认状态融入侧栏背景且不显示独立边框；鼠标悬停或键盘聚焦
  时才显示浅色圆角底，图标和箭头同时变为蓝色。文件夹图标使用微软 365
  `Folder Open` 的原始填充矢量路径，默认颜色为 `#B1B3B3`，不得替换为线框近似图。
  应用按钮上方不重复显示待应用状态文字。
- “应用”和“关闭”纵向排列，统一使用 `80 DLU` 宽、`18 DLU` 高的全局操作
  按钮尺寸，并在导航栏内水平居中。
- 页面切换必须保持窗口稳定，不得出现窗口消失、重新定位或明显空白帧。
- 页面切换只更新内容子页面，禁止重建或重新激活顶层窗口的非客户区。

## 2. 尺寸与间距

- 所有只有一行内容的卡片必须使用同一个共享高度常量。单行卡片指“标题或名称
  + 一个开关、下拉框、状态或按钮”的结构。
- 单行卡片的圆角、边框、左右内边距和上下留白必须完全一致。右侧控件在卡片内
  垂直居中。
- 包含说明、错误提示或多组控件的卡片属于多行卡片，可按内容增加高度，但仍须
  使用统一的页面网格、内边距和圆角。
- 同级卡片使用相同间距；区域之间的间距必须明显大于控件内部间距。
- 页面中同一列控件的左边缘和右边缘必须建立明确的对齐基准，不得凭视觉估算
  单独放置。
- 恢复操作固定放在右侧内容区左下方，统一命名为“恢复本页默认”，并使用全局
  次要按钮尺寸。
- 提交前必须检查所有页面窗口尺寸、单行卡片高度、卡片边缘和公共按钮尺寸的
  一致性。

## 3. 圆角和边框

- 尽量避免可见的直角矩形。卡片、按钮、下拉框、分段控件和预览背景均使用所属
  类别的统一圆角。
- 卡片圆角复用 `kCardRadiusDlu`；普通按钮、下拉框和输入框统一复用
  `kControlCornerRadiusPx`，其值为 `5 px` 逻辑半径并随 DPI 缩放。所有公共函数
  必须把该值解释为半径，创建窗口区域时转换为两倍直径；禁止页面内为这些控件
  写入独立圆角值。
- 圆角必须进行真实区域裁切，四角外不得残留白色或背景色直角。
- 边框使用低对比度细线。不得通过加深、加粗边框弥补层级不清。
- 自绘卡片是页面控件的背景兄弟窗口，必须固定在同级窗口底层并裁掉兄弟控件区域；
  点击卡片空白处或触发卡片重绘时，不得覆盖标题、图标、按钮等前景内容。
- 卡片背景本身不参与交互，不得接受焦点、按压或点击状态；鼠标点击卡片空白区时
  不得触发整张卡片或复杂预览的重复重绘。
- 所有页面的下拉框收起状态统一使用公共绘制函数和单个物理像素边框；DPI 缩放
  只改变控件尺寸与圆角，不得把边框放大为双像素，也不得叠加系统原生边框。
- 分隔线两端与相邻主要内容边缘对齐，并使用统一的淡色与粗细。

## 4. 控件分类

- 同类按钮使用统一宽度和高度。普通操作、次要操作、临时操作分别复用全局尺寸
  常量，不得按页面随意设置。
- 开关采用紧凑尺寸，轨道和白色圆点保持清晰但不过度放大。开关左侧显示当前
  状态“开”或“关”。
- 开关轨道必须按标准胶囊形绘制：两端为与轨道高度匹配的半圆，中段保持平直；
  白色圆点为抗锯齿正圆并在轨道内精确居中。不得对开关窗口本身硬裁切圆角，
  也不得出现鹅卵石形、锯齿边缘或鼠标点击后残留的虚线框。
- 单行卡片中的开关轨道右边缘，必须与同列下拉框及其他右侧控件的右边缘对齐。
- 一体式切换按钮使用紧凑高度。未选区域使用比卡片稍深的中性底色，选中区域
  使用系统强调色。
- 自绘切换按钮与开关必须独占悬停状态，不得再触发系统原生按钮热状态；悬停重绘
  使用双缓冲，文字、轨道和白色圆点均不得闪烁。
- 切换按钮的可见选中区域左边缘须与同列上方标题文字左边缘对齐，不能只对齐
  隐藏的外层边界。

## 5. 下拉框与展开列表

- 下拉框宽度根据最长显示文字、左右内边距和箭头安全区确定，不得无意义铺满
  整行，也不得让末尾文字进入箭头区域。
- 下拉箭头使用原有细线式箭头。展开时只改变方向，不得替换为实心三角形或其他
  图形。
- 展开列表统一参考 Windows 11：面板使用圆角、淡色边框和轻微阴影，并与下拉框
  保留小间距。
- 当前选项使用浅灰底色和左侧短强调线。悬停项仅使用更淡的中性底色，不使用
  整块蓝色高亮。
- 展开面板与下拉框等宽，选项高度和文字左边距统一。
- 禁用的下拉框保持可见和原有位置，降低对比度并禁止操作，不能直接隐藏。

## 6. 候选框页面定稿布局

右侧内容区采用左右两栏，比例约为 `60% : 40%`。左栏设置，右栏预览；左右栏
顶部和底部使用同一基线。

### 6.1 左栏

左栏从上到下放置三张卡片：

1. “亚克力磨砂效果”单行卡片。左侧为名称，右侧依次为“开/关”和紧凑开关。
2. “界面模式”单行卡片。名称和下拉框处于同一行；卡片高度与第一张卡片完全
   一致。下拉框只占满足内容所需的紧凑宽度，选项为“跟随系统”“始终浅色”
   “始终深色”。
3. 配色设置卡片。卡片不显示“配色方案”等重复标题，顶部仅放置“成组设置 /
   单独设置”一体式紧凑切换按钮。

切换按钮与下拉设置区之间保留明确的区域留白，利用卡片下方空间，不能让下拉框
紧贴切换按钮。

配色设置使用固定的“标签列 + 下拉框列”：

- 成组设置：显示“浅色/深色”和一个下拉框。
- 单独设置：第一行显示“浅色”和浅色下拉框，第二行显示“深色”和深色下拉框。
- 成组设置的下拉框与单独设置的浅色、深色下拉框使用相同的水平起点和右边缘。
- 切换成组和单独设置时必须预留稳定区域，其他卡片和右侧预览不得移动、裁切或
  出现残影。

界面模式与单独设置之间遵循以下联动：

- “跟随系统”：浅色和深色均可设置。
- “始终浅色”：浅色可设置；深色保持可见但禁用。
- “始终深色”：深色可设置；浅色保持可见但禁用。
- 用户选择“跟随系统”时，配色区自动切换到“成组设置”；选择“始终浅色”或
  “始终深色”时，配色区自动切换到“单独设置”。自动切换只提供合适的默认落点，
  不能禁用用户随后手动切换成组或单独设置的能力。

### 6.2 右栏

- 右栏上下放置浅色和深色预览，两个区域尺寸完全一致。
- 不在渐变背景外再套预览卡片。渐变背景本身就是带圆角和淡色边框的预览卡片。
- “浅色预览”和“深色预览”放在各自背景卡片左上角。
- 实际候选框顶部与预览标题顶部齐平；候选框顶部、底部到背景卡片的距离相等。
- 每个候选框显示五个候选项，各项之间的垂直间距必须相同。
- 候选框必须根据当前配置真实渲染字体、字号、字形、布局、圆角、间距和颜色，
  不得为了填充预览区随意拉伸宽度。
- 亚克力启用时应清楚显示半透明、背景模糊和轻微高光边缘，但不得使用夸张的
  玻璃拟态效果。预览使用柔和、低对比度的漫反射层增强磨砂玻璃质感，不使用
  可见颗粒噪点，也不得明显拖慢页面首次显示。
- 预览背景须有足以透过半透明候选框辨认的冷暖色差，并使用大范围柔边光晕；
  不得使用生硬色块、高饱和装饰或干扰候选文字阅读的纹理。
- 切换到页面时预览应立即可见；后续精确渲染不得先显示空白区域。

## 7. 字体页面定稿布局

- 字体页使用上下两张等宽卡片，整体左右边缘、顶边和底边与其他页面主体区域完全
  一致。上方卡片承载字体设置，下方卡片承载预览控制与实际预览，两卡片间距统一。
- 上方设置区采用 Word 字体对话框式四列布局。第一列为“文字类型”，使用“输入码 /
  候选文字 / 候选序号 / 注释文字”四项纵向一体式选择器；第二列上下排列“中文字体”
  和“西文字体”两个独立字体下拉框；右侧只保留一列共用“字形”和一列共用“字号”。
- 字体设置区下方左对齐放置“浅色 / 深色”和“横排 / 竖排”两组紧凑分段按钮，
  每个分段的宽度、高度和圆角均与候选框页“成组设置 / 单独设置”按钮完全相同，
  两组之间保留明确间距，与实际预览区域只保留紧凑但清晰的间距；浅深切换只控制
  预览，不修改外观配置或产生未应用标识。
- 两组预览按钮右侧显示低对比度辅助文字“仅影响预览，不会保存或应用到实际候选窗”，
  明确说明这些切换不会进入待应用状态。
- 预览放在字体设置卡片下方的独立卡片中并占用剩余宽度和高度；操作顺序为先选择
  文字类型并设置字体，再向下查看真实渲染结果。
- 字体列不得再增加“字体”总标题。“中文字体”直接位于首行，并与“文字类型 / 字形 /
  字号”标题处于同一水平基线；“西文字体”作为字体列第二行标题。
- 字形与字号采用 Word 字体对话框式组合结构：顶部矩形框固定显示当前值，下方为
  常驻展开列表。各列表使用统一的自然行高；字号按可用高度显示尽可能多的完整选项，
  不强制显示五项，也不得显示被裁切的半行。当前项尽量位于可见区域中间。
- 文字类型、字体、字形、字号四列的顶边和底边必须对齐，视觉高度完全相同。中文
  和西文字体标签及下拉框在各自行内垂直居中；四列底边以“西文字体”下拉框的实际
  下边缘为准，并在所有 DPI 下按像素精确对齐。
- 共用字形或字号发生选择后，同步写入当前文字类型的中文和西文字体设置；中文与
  西文字体名称仍分别选择。读取到两种语言原有字号或字形不一致时，共用列表不
  预选任何项，用户主动选择后才同步，不得在打开页面时静默覆盖原值。
- 预览必须读取当前生效的 `weasel` 配置，使用其中的主题模式、亚克力状态、配色、
  圆角、边框、外边距、预编辑间距、候选间距、高亮内边距和字体回退值；字体页
  草稿启用后，再按文字类型和中文/西文覆盖对应字体、字号及字形。
- 预览中的字号始终按配置点数和当前 DPI 原尺寸绘制。空间不足时裁切候选窗内容，
  不得缩放字体或候选窗来制造能够放下的假象。
- 点击文字类型时，预览中对应的输入码、候选文字、候选序号或注释文字显示约一秒
  的淡蓝色圆角定位提示后自动淡出；不得改变文字尺寸、位置或候选框布局。同一类型
  再次点击时重新显示提示，提示结束后恢复完全按配置渲染的预览。
- 预编辑文本可能包含汉字与西文输入码，不得因“输入码通常为西文”而禁用中文字体。
  预览须使用中西文混排示例，并按实际运行时规则逐段应用中文字体和西文字体。
- 字体页预览的配色、字体、字号、字形、布局、间距、圆角和边框等均读取实际配置，
  但候选数量设为独立例外，任何配置下均不得超过五个。示例同时包含中文与西文候选
  以及中文与西文注释，
  以便分别检查输入码、候选文字、候选序号和注释文字四种字体设置的真实效果。
  候选和注释须与预编辑文本一样按实际运行时规则逐段应用中文字体和西文字体。

## 8. 页面状态与交互

- 控件变化先写入页面草稿状态。“应用”统一保存所有页面的更改并执行必要部署。
- 页面切换不得丢失尚未应用的草稿状态。
- 切换页面时不得询问是否放弃更改；未应用提示仅在关闭整个设置窗口时出现。
- 关闭窗口时，无论一个还是多个页面存在未应用更改，只允许显示一次统一确认提示；
  确认后统一放弃全部未应用更改，取消后保持当前页面和全部草稿不变。
- 禁用状态、下载状态、待应用状态和错误状态不得引发布局移动。
- 动态更新只重绘发生变化的区域，避免整页闪烁。
- 所有交互必须支持键盘导航，并保持清晰且统一的焦点样式。

### 8.1 状态图标页

- 状态图标统一为“中文 / 西文 / 大写”三种；大写锁定后无论原来处于中文还是西文
  状态，都使用同一个“大写”图标。
- 内置默认图标固定为红底“中”、蓝底“a”和深色底“A”三枚独立资源；大写状态
  不再根据其他图标动态叠加角标。内置 ICO 包含 16、20、24、28、32、40、48、64、
  72、80、96、128、256 像素的 32 位透明帧，以覆盖常用 DPI 缩放。
- 页面保持“任务栏图标 / 任务栏预览”两张卡片；三种图标在同一张紧凑设置卡片中，
  页面剩余高度优先提供给任务栏实景预览。
- 设置卡片顶部使用“全局图标 / 方案图标”范围切换。输入方案专属范围必须提供
  输入方案下拉框，并继续复用中文、西文、大写三行编辑结构，不另开页面或增加第二个
  任务栏图标位。
- 每个输入方案的三种图标均可独立选择，也可明确设为“使用全局”。“恢复本方案默认”
  清除设置界面保存的覆盖，使其重新采用输入方案文件中已有的原生图标配置；“使用全局”
  则明确跳过该项原生配置。
- 运行时解析顺序固定为“设置界面的输入方案专属图标 → 输入方案文件的原生图标 →
  全局自定义图标 → 小狼毫内置默认图标”。如果用户为某项选择“使用全局”，该项顺序
  改为“全局自定义图标 → 小狼毫内置默认图标”。大写状态允许输入方案文件使用
  `schema/caps_icon`，未配置时继续回退。
- 全局设置和输入方案专属设置只决定同一个任务栏图标位最终加载哪一张图片，任何状态
  和输入方案都不得额外创建第二个图标位。
- 三种任务栏状态使用连续分段按钮，同组按钮之间不得留缝或出现重复圆角；高度统一
  为公共紧凑切换高度。
- 任务栏预览必须使用当前草稿中的对应图标，并以系统托盘实际显示尺寸绘制图标；
  不得为了醒目而单独放大图标。
- “更换图标”打开统一的图标库选择窗口，至少显示内置默认图标、对应状态可用的
  其他内置颜色、以前导入的图标、导入新图标和删除操作。内置备选资源安装在程序目录
  `icons/status`，保持只读且不得混入用户图标库。选择图标只修改页面草稿，仍须点击
  “应用”才部署生效。
- 用户导入的 PNG/ICO 文件立即保存到用户文件夹的 `icons/status/library`，不得写入
  程序安装目录。文件名保留可辨识的原名称并追加内容摘要；相同内容重复导入时复用
  已有文件。旧版固定文件仍须可见，并在再次应用时迁移到图标库。
- 图标库文件使用相对于用户文件夹可迁移的存储位置。正在被已应用设置或当前草稿
  引用的文件不得直接删除；其他库文件删除前必须确认。
