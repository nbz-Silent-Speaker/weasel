# 小狼毫设置界面设计规则

本文件是小狼毫设置界面的强制设计规范。现有页面调整和后续新增页面均须遵守；
不得在单个页面中临时定义另一套尺寸、圆角、按钮或对齐方式。

## 1. 固定框架

- 所有设置页面共用同一个顶层窗口，切换页面不得改变窗口尺寸和位置。
- 内容框架以 `SettingsNavigation.h` 为唯一尺寸来源：内容区 `540 × 286 DLU`，
  导航栏宽度 `116 DLU`，页面内容边距 `14 DLU`，页面主体宽度
  `512 DLU`。
- 窗口标题统一为“小狼毫设置”。右侧内容区不重复显示当前页面大标题，当前页
  由左侧导航栏选中状态表达。
- 左侧导航栏使用与右侧内容区可辨别但克制的浅色底色，并始终保持固定宽度。
- 用户文件夹固定在导航栏最下方。状态文字在操作按钮上方水平居中。
- “应用”和“关闭”纵向排列，使用全局统一尺寸。
- 页面切换必须保持窗口稳定，不得出现窗口消失、重新定位或明显空白帧。

## 2. 尺寸与间距

- 所有只有一行内容的卡片必须使用同一个共享高度常量。单行卡片指“标题或名称
  + 一个开关、下拉框、状态或按钮”的结构。
- 单行卡片的圆角、边框、左右内边距和上下留白必须完全一致。右侧控件在卡片内
  垂直居中。
- 包含说明、错误提示或多组控件的卡片属于多行卡片，可按内容增加高度，但仍须
  使用统一的页面网格、内边距和圆角。
- 同级卡片使用相同间距；区域之间的间距必须明显大于控件内部间距。
- 页面中同一列控件的左边缘和右边缘必须建立明确的对齐基准，不得凭视觉估算
  单独放置。
- 恢复操作固定放在右侧内容区左下方，统一命名为“恢复本页默认”，并使用全局
  次要按钮尺寸。
- 提交前必须检查所有页面窗口尺寸、单行卡片高度、卡片边缘和公共按钮尺寸的
  一致性。

## 3. 圆角和边框

- 尽量避免可见的直角矩形。卡片、按钮、下拉框、分段控件和预览背景均使用所属
  类别的统一圆角。
- 卡片圆角复用 `kCardRadiusDlu`，普通控件圆角复用 `kControlRadiusDlu`；禁止
  页面内写入独立圆角值。
- 圆角必须进行真实区域裁切，四角外不得残留白色或背景色直角。
- 边框使用低对比度细线。不得通过加深、加粗边框弥补层级不清。
- 分隔线两端与相邻主要内容边缘对齐，并使用统一的淡色与粗细。

## 4. 控件分类

- 同类按钮使用统一宽度和高度。普通操作、次要操作、临时操作分别复用全局尺寸
  常量，不得按页面随意设置。
- 开关采用紧凑尺寸，轨道和白色圆点保持清晰但不过度放大。开关左侧显示当前
  状态“开”或“关”。
- 单行卡片中的开关轨道右边缘，必须与同列下拉框及其他右侧控件的右边缘对齐。
- 一体式切换按钮使用紧凑高度。未选区域使用比卡片稍深的中性底色，选中区域
  使用系统强调色。
- 切换按钮的可见选中区域左边缘须与同列上方标题文字左边缘对齐，不能只对齐
  隐藏的外层边界。

## 5. 下拉框与展开列表

- 下拉框宽度根据最长显示文字、左右内边距和箭头安全区确定，不得无意义铺满
  整行，也不得让末尾文字进入箭头区域。
- 下拉箭头使用原有细线式箭头。展开时只改变方向，不得替换为实心三角形或其他
  图形。
- 展开列表统一参考 Windows 11：面板使用圆角、淡色边框和轻微阴影，并与下拉框
  保留小间距。
- 当前选项使用浅灰底色和左侧短强调线。悬停项仅使用更淡的中性底色，不使用
  整块蓝色高亮。
- 展开面板与下拉框等宽，选项高度和文字左边距统一。
- 禁用的下拉框保持可见和原有位置，降低对比度并禁止操作，不能直接隐藏。

## 6. 候选框页面定稿布局

右侧内容区采用左右两栏，比例约为 `40% : 60%`。左栏设置，右栏预览；左右栏
顶部和底部使用同一基线。

### 6.1 左栏

左栏从上到下放置三张卡片：

1. “亚克力磨砂效果”单行卡片。左侧为名称，右侧依次为“开/关”和紧凑开关。
2. “界面模式”单行卡片。名称和下拉框处于同一行；卡片高度与第一张卡片完全
   一致。下拉框只占满足内容所需的紧凑宽度，选项为“跟随系统”“始终浅色”
   “始终深色”。
3. 配色设置卡片。卡片不显示“配色方案”等重复标题，顶部仅放置“成组设置 /
   单独设置”一体式紧凑切换按钮。

切换按钮与下拉设置区之间保留明确的区域留白，利用卡片下方空间，不能让下拉框
紧贴切换按钮。

配色设置使用固定的“标签列 + 下拉框列”：

- 成组设置：显示“浅色/深色”和一个下拉框。
- 单独设置：第一行显示“浅色”和浅色下拉框，第二行显示“深色”和深色下拉框。
- 成组设置的下拉框与单独设置的浅色、深色下拉框使用相同的水平起点和右边缘。
- 切换成组和单独设置时必须预留稳定区域，其他卡片和右侧预览不得移动、裁切或
  出现残影。

界面模式与单独设置之间遵循以下联动：

- “跟随系统”：浅色和深色均可设置。
- “始终浅色”：浅色可设置；深色保持可见但禁用。
- “始终深色”：深色可设置；浅色保持可见但禁用。
- 用户选择“跟随系统”时，配色区自动切换到“成组设置”；选择“始终浅色”或
  “始终深色”时，配色区自动切换到“单独设置”。自动切换只提供合适的默认落点，
  不能禁用用户随后手动切换成组或单独设置的能力。

### 6.2 右栏

- 右栏上下放置浅色和深色预览，两个区域尺寸完全一致。
- 不在渐变背景外再套预览卡片。渐变背景本身就是带圆角和淡色边框的预览卡片。
- “浅色预览”和“深色预览”放在各自背景卡片左上角。
- 实际候选框顶部与预览标题顶部齐平；候选框顶部、底部到背景卡片的距离相等。
- 每个候选框显示四个候选项。
- 候选框必须根据当前配置真实渲染字体、字号、字形、布局、圆角、间距和颜色，
  不得为了填充预览区随意拉伸宽度。
- 亚克力启用时应清楚显示半透明、背景模糊和轻微高光边缘，但不得使用夸张的
  玻璃拟态效果。
- 切换到页面时预览应立即可见；后续精确渲染不得先显示空白区域。

## 7. 页面状态与交互

- 控件变化先写入页面草稿状态。“应用”统一保存所有页面的更改并执行必要部署。
- 页面切换不得丢失尚未应用的草稿状态。
- 禁用状态、下载状态、待应用状态和错误状态不得引发布局移动。
- 动态更新只重绘发生变化的区域，避免整页闪烁。
- 所有交互必须支持键盘导航，并保持清晰且统一的焦点样式。

## 8. 提交前验收清单

- 四个现有设置页及以后新增页面的外框尺寸完全一致。
- 所有单行卡片高度完全一致。
- 卡片、按钮、下拉框、切换控件和预览背景使用对应的统一圆角。
- 页面内没有因裁切失败产生的直角白底、残影或文字遮挡。
- 所有同列控件的左右边缘符合已定义的对齐关系。
- 成组/单独设置及界面模式的全部组合均无移动、重叠或裁切。
- 下拉列表符合 Windows 11 展开样式，文字与箭头之间留有安全区域。
- 浅色、深色预览均显示四个候选项，尺寸和样式来自实际配置。
- “恢复本页默认”、应用、关闭及状态文字的位置和尺寸符合公共规范。
- 100%、125%、150%、175% 和 200% DPI 下均不超出屏幕、不变形、不出现新滚动条。
